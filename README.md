# バス、次いつ？

自分用の「次のバス」表示アプリ（PWA）。Androidの Chrome で開いて「ホーム画面に追加」すると、アプリみたいに使える。

- 区間：ダイハツ前→沼津駅／大手町→ダイハツ前／沼津駅⇔八重／二瀬川⇔大手町
- 平日と土日祝のダイヤを自動で切り替える（祝日は `holidays.js`。毎年末に翌年分を足す）
- 時刻表は `timetable.js`。ダイヤ改正のときは `python3 tools/update_timetable.py` で作り直す
- 電波がなくても開ける（`sw.js` がキャッシュ。直したら `CACHE` の版を上げる）
- 動作確認で時刻を固定したいときは `?now=2026-10-04T12:00` を付けて開く

時刻表の出典：NAVITIME（遅れ・運休は反映されない）
